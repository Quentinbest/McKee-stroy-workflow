## Diversity Alternatives for 1-4-3

- **A / action**: 林汐把自己的档案员指环卡进广播扣，让弹簧无法复位。她必须留在桥台承受九十秒冲击，阿蓁则带诊所的人决定是否继续报出名字。
- **B / relationship_pressure**: 林汐接通诊所却不宣布决定，只把两个槽和九十秒代价说清。阿蓁沉默后要求全城频道开放，让低地居民自己回答是否承担降载。
- **C / information_control**: 林汐先广播母亲记忆的校验码和七码闸命令，再把原始回声匣投入燃料槽。证据成为全城可复制的事实，母亲的声音却永远消失。
