## Locked Human Authority

- Premise: 当防洪城以死者的最后记忆驱动海堤，一名记忆档案员发现母亲的临终记忆证明城市曾主动淹没低地；为了保护仍住在低地的妹妹，她必须在抹去证据、维持海堤与公开真相、让全城共同承担风暴之间作出选择。

## Diversity Alternatives for 1-4-3

- **A / action**: 林汐把自己的档案员指环卡进广播扣，让弹簧无法复位。她必须留在桥台承受九十秒冲击，阿蓁则带诊所的人决定是否继续报出名字。
- **B / relationship_pressure**: 林汐接通诊所却不宣布决定，只把两个槽和九十秒代价说清。阿蓁沉默后要求全城频道开放，让低地居民自己回答是否承担降载。
- **C / information_control**: 林汐先广播母亲记忆的校验码和七码闸命令，再把原始回声匣投入燃料槽。证据成为全城可复制的事实，母亲的声音却永远消失。

## Batch-Level Risks

- **cross_scene_homogeneity / high**: 多数 Beat 采用“具体物件或声音开场、克制对话推进、物件余波收尾”的同一审美模板；机制标签不同，但阅读质感仍趋同。 机制覆盖率不能作为成品多样性的代理指标。
- **information_mechanism_repetition / medium**: 1-1-2 与 1-2-3 都依赖回声匣漏出声音完成证据发现。 Beat 级 critic 能发现局部重复，但需要 batch 边界汇总才能判断跨场递减效应。
- **self_review_distortion / high**: 本环境没有独立 critic 调用；12 次审查均由同一上下文完成。 审查发现只能视为风险提示，不能作为质量通过证据。
