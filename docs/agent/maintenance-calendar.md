# Maintenance Calendar

| Cadence | Activity | Owner | Evidence |
|---|---|---|---|
| Per change | contracts, generation, tests, security, docs | change owner | CI and task evidence |
| Monthly | stale tasks, adapter drift, references, dependency health | framework | maintenance task |
| Quarterly | official harness docs and compatibility review | adapter owners | compatibility ledger |
| Major release | story E2E, security review, rollback exercise | release/security/domain | release evidence |
| Annual | archive obsolete adapters and reassess harness support | maintainers | ADR and roadmap |

## Initial Dates

- First monthly review: 2026-07-01.
- First quarterly review: 2026-09-01.
- First rollback exercise: before stable `1.0.0`.
- First annual support review: 2027-06-01.
