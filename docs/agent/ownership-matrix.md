# Ownership Matrix

| Area | Accountable owner | Review responsibility |
|---|---|---|
| Domain methodology | human story-method owner | terminology, quality gates, artifact semantics |
| Agent framework | framework maintainer | schemas, generator, instruction architecture |
| Harness adapters | adapter maintainer | discovery, configs, native compatibility |
| Security and privacy | security owner | permissions, incidents, external code/data |
| Release | release owner | version, evidence, deprecation, rollback |
| Story project | story owner | private data, persona, quality, publication |

Roles may be held by one person in a small project, but each approval must state
which responsibility is being exercised.
