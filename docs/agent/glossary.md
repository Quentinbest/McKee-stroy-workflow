# Canonical Glossary

| English | 简体中文 | Meaning |
|---|---|---|
| Controlling Idea | 控制思想 | value plus cause proven by the story |
| Story Spine | 故事脊柱 | causal chain from inciting incident through resolution |
| Inciting Incident | 激励事件 | event that radically upsets the protagonist's life |
| Progressive Complication | 递进复杂化 | escalating obstacle that changes tactics or stakes |
| Crisis | 危机 | irreconcilable dilemma before the climax |
| Climax | 高潮 | final action answering the major dramatic question |
| Resolution | 结局 | aftermath after the climax |
| Gap | 鸿沟 | difference between expected and actual result |
| Beat | 节拍 | smallest action/reaction unit of changed behavior |
| Scene | 场景 | conflict producing a meaningful value change |
| Sequence | 段落 | linked scenes culminating in a larger change |
| Act | 幕 | major movement ending in an irreversible turn |
| Value Charge | 价值电荷 | positive or negative state of a story value |
| Turning Point | 转折点 | event opening a gap and redirecting action |
| Object of Desire | 欲望对象 | conscious and/or unconscious goal |
| Forces of Antagonism | 对抗力量 | inner, personal, and extra-personal opposition |
| Negation of the Negation | 否定之否定 | corruption or inversion of a positive value |
| Setup and Payoff | 铺垫与兑现 | planted element and later meaningful consequence |
| Text and Subtext | 文本与潜台词 | spoken surface versus underlying desire/action |
| Author Persona | 作者人格 | private project-level decision filter, not the human |
| Skill | 技能 | reusable bounded procedure |
| Role | 角色 | delegated capability with constrained authority |
| Artifact | 工件 | versioned workflow input or output |
| Harness | 智能体运行环境 | host such as Claude Code, Cursor, Pi, OpenCode, Codex |

Identifiers and filenames remain English kebab-case. Chinese translations are
for prose and reader-facing documentation.
