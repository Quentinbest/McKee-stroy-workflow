# Changelog

## 1.0.0-rc.1 - 2026-06-06

- Established canonical `src/skills/`, `src/roles/`, templates, provenance, and
  external wiki dependency mapping.
- Added universal/scoped instructions and versioned task, skill, role, artifact,
  control-plane, delegation, and handoff contracts.
- Added deterministic adapters for Claude Code, Cursor, Pi, OpenCode, and Codex.
- Added drift, security, documentation, contract, integration, E2E, smoke, and
  conformance verification.
- Added resumable task state, ledgers, checkpoints, stop-loss, and delegation
  isolation.
- Added governance, release evidence, and rollback runbooks.

This is a release candidate. Stable release remains gated on human literary
quality and operational usability review.
